MP4 to MP3 Converter — Portable Version
=======================================

How to use
----------
1. Unzip this folder anywhere (Desktop, USB drive, etc.).
2. Double-click Mp4ToMp3.exe
3. Add or drag & drop MP4 files
4. Choose an output folder
5. Click Convert

Requirements
------------
- Windows 10 / 11 (64-bit)
- No .NET installation needed
- No admin rights needed

Notes
-----
- Existing MP3 files in the output folder are skipped (not overwritten).
